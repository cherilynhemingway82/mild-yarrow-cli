# mild-yarrow-cli

Platform engineer · Rust and Tower

处理日常小任务的工具

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```
